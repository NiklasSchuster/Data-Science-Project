# Data-Science-Project

# modelling.ipynb
Contains the code to run the holdout and expanding window machine learning model over all selected grid points in Australia.

# analysis.ipynb
Contains the code to read the log-files from the modelling.ipynb notebook and perform statistical evaluations on them.

# Logfiles
The provided logfiles are the ones produced for the research question 1 (1 log file for slope, 1 for curvature) and for research question 2 (1 log file for each grid point cluster).
